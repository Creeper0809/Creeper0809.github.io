네트워크 접근 제어와 비동기 백엔드를 개발하고, 인증 로그를 활용한 보안 모델을 연구합니다. VPN 기반 공방전을 운영했고, 월별 경영관리 데이터를 처리하는 보고서 백엔드를 개발했습니다.

[GitHub](https://github.com/Creeper0809) · [알고리즘 풀이](/tags/)

## 경력

### SK하이닉스 프로젝트 · 프리랜서

**2026.10–2026.11**

- CapEx, OpEx, OI 데이터를 처리하는 월별 경영관리 보고서 시스템에서 AI 분석과 채팅 API를 개발했습니다. LangGraph로 분석 흐름을 구성하고, 집계값이 같은 분석 화면은 한 번의 LLM 호출 결과를 공유하도록 했습니다.
- 업로드 시점에 월별 합계를 미리 계산하도록 변경했습니다. 합성 OpEx 데이터 15만 행을 로컬에서 변경 전후 30회씩 조회했을 때 p95 응답 시간이 167.9ms에서 13.5ms로 줄었습니다.

### 클라우드에어 · 인턴

**2025.12–2026.07**

- 팀장으로 청주대학교 CTF와 오스트리아 공방전 플랫폼의 개발과 운영을 맡았습니다. OpenVPN으로 팀별 관리망을 분리하고, 배포 자동화와 네트워크 관리 API를 개발했습니다.
- 오스트리아 행사에서는 3개 대학 20명이 참가한 6시간 공방전을 운영했습니다. 현장에서 VPN 재접속이 반복되자 두 프로세스로 연결을 분산해, 참가자가 기존 설정 파일로 다시 접속할 수 있게 했습니다.
