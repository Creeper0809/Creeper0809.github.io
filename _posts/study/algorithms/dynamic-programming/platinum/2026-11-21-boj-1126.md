## 문제 태그

- DP

## 아이디어

1. 처음에는 3차원 dp로 dp[사용한 블럭 개수][1번탑 높이][2번탑 높이] 이런식으로 하려 했지만 어느 구간이 정답인지 모를 뿐더러 메모리도 부족하다
2. 고로 문제를 다시 천천히 읽어 재해석하면 블럭을 최대 N개 사용했을 때 높이 차이가 0 이때의 최대 높이를 구하는것이다
3. 그래서 dp 테이블을 [dp[사용한 블럭 개수][높이의차] = 현재 높이차에서의 최대 높이]로 두고 케이스를 쪼개봐야한다
4. 블럭을 설치 하지 않는다 → dp[i][j] = max(dp[i][j],dp[i-1][j])
5. 블럭을 설치한다 이때 두가지 케이스로 나뉜다
    1. 블럭을 높은쪽에 설치한다 → 높이의차를 더 크게 만든다(하지만 공통 높이는 달라지지 않음) → dp[i][j + height(i)] = max(dp[i][j + height(i)],dp[i-1][j])
    2. 블럭을 낮은쪽에 설치한다
        1. 높이의 차가 줄어든다 → j > height(i) → 공통 높이가 높아짐 → dp[i][j - height(i)] = max(dp[i][j - height(i)],dp[i-1][j] + height(i))
        2. 높이의 차가 역전된다 → j < height(i) → 공통 높이가 높아지기는 하는데 온전히 블럭 높이만큼 공통된 높이가 오르는게 아님 → dp[i][height(i) - j] = max(dp[i][height(i) - j],dp[i-1][j] + height(i) - j)
6. 정답은 dp[N][0]에 담기게 됨

## 정답

```python
N = int(input())
block_height = list(map(int, input().split()))

MAXD = sum(block_height)
dp = [[-1] * (MAXD + 1) for _ in range(N)]
dp[0][block_height[0]] = 0
dp[0][0] = 0

for i in range(1, N):
    h = block_height[i]
    for d in range(MAXD):
        prev = dp[i-1][d]
        if prev == -1:
            continue
        dp[i][d] = max(dp[i][d], prev)
        if d + h <= MAXD:
            dp[i][d + h] = max(dp[i][d + h], prev)
        if h > d:
            new_d = h - d
            dp[i][new_d] = max(dp[i][new_d], prev + d)
        else:
            new_d = d-h
            dp[i][new_d] = max(dp[i][new_d], prev + h)
print(dp[N-1][0] if dp[N-1][0] > 0 else -1)
```
