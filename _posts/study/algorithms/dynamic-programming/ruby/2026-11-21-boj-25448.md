## 문제 태그

- EGZ 정리
- 구성적 재귀 (합성수 분해)
- subset sum mod p
- critical number
- 비트셋 DP 최적화

---

## 문제 요약

### 입력

- 정수 N과 길이 2N-1 배열 a가 주어진다.
- 각 원소는 0 <= a_i < N.

### 출력

- 원소 N개를 출력하되 합이 N의 배수여야 한다.
- 가능한 답이 여러 개면 아무거나 가능하다.

### 제약

- 1 <= N <= 500000
- 시간 제한 1초, 메모리 제한 512MB

### 목표 재정의

- 2N-1개 중 N개를 실제로 뽑아 합을 0 mod N으로 만드는 구성 알고리즘을 만든다.

---

## 아이디어

### 1) 핵심 관찰

- 정답 존재성은 EGZ 정리로 항상 보장된다.
- 합성수 N 처리 방식은 18792와 동일하게 N=a*b 재귀 분해를 사용한다.
- 병목은 소수 p 케이스의 subset sum mod p이고, N<=500000에서는 여기 최적화가 필수다.

<aside markdown="1">
💡

**왜 이 관찰이 성립하는가?**

- 합성수 분해 재귀는 정당성이 이미 고정되어 있으므로, 성능 차이는 소수 케이스 구현에서 결정된다.
- 소수 케이스를 그대로 p-1 아이템 DP로 돌리면 $$O(p^2/64)$$가 되어 큰 소수에서 시간 초과가 난다.
</aside>

### 2) 정리/성질/공식

- 소수 p에서 정렬/페어링 후 목표는 diff 멀티셋 부분합을 맞추는 문제다.
- D = diff의 서로 다른 나머지 개수, C = floor(2*sqrt(p-2)).
- D>=C면 서로 다른 원소 C개만으로도 모든 나머지를 만들 수 있다는 critical number 성질을 사용한다.

$$
\left(x_0 + \sum_{j=1}^{p-1} x_j\right) + \sum_{j \in T} d_j \equiv 0 \pmod p
$$

$$
m = \begin{cases}
C & (D\ge C) \\
O(D\log p) & (D<C)
\end{cases},
\qquad
\text{DP cost } O\left(\frac{p\cdot m}{64}\right)
$$

### 3) 알고리즘 설계

1. spf를 계산하고 solve_rec(n, arr) 재귀를 둔다.
2. 합성수면 x=spf[n], y=n/x로 그룹화 재귀 수행.
3. 소수 p면:
    - 정렬 후 빠른 종료(x_i==x_{i+p-1}) 확인
    - diff, target, residue 빈도 계산
    - D>=C: 서로 다른 residue C개로 0/1 비트셋 DP
    - D<C: residue 개수를 binary splitting해 bounded 비트셋 DP
    - parent 역추적으로 residue 사용 개수 복원 후 실제 페어 선택으로 매핑

### 4) 케이스 분기

- N=1, N=2: 베이스 케이스
- N 합성수: 그룹 몫 재귀
- N 소수:
    - 중복 구간 존재 -> 즉시 답
    - 없으면 D>=C/D<C 분기 최적화

### 5) 정당성 요약

- 합성수 재귀의 정당성은 x 배수 그룹 + y 모듈러 선택의 결합으로 확보된다.
- 소수 케이스의 페어 선택은 diff 부분합 선택과 동치다.
- D>=C 분기는 critical number 정리로 target 도달이 보장된다.
- D<C 분기는 bounded 아이템을 동치인 0/1 아이템으로 분해한 DP라 완전성을 유지한다.
- 따라서 복원된 인덱스 집합은 항상 크기 N, 합 %N==0을 만족한다.

---

## 구현 포인트

### 자료구조 선택

- vector<unsigned long long>: 회전 비트셋 DP
- vector<Item>: residue 아이템(가중치, residue id, 사용량)
- vector<vector<int>> 또는 평탄화 배열: 그룹 인덱스 복원

### 인덱싱/경계

- 모든 인덱스는 0-based로 관리한다.
- 비트셋 마지막 워드에 last_mask를 반드시 적용해 p 이상 비트를 차단한다.

### 오버플로우/정밀도

- 그룹 합은 ll 사용
- r * t % p 계산 시 1LL * r * t로 승격 후 모듈러

### 디버깅 포인트

- pick_cnt가 실제 residue 위치 개수를 넘지 않는지 체크
- binary splitting된 아이템의 take 합이 원래 빈도와 일치하는지 점검

#include <bits/stdc++.h>

using namespace std;

using ll = long long;
using pii = pair<int, int>;
using vi = vector<int>;
using vll = vector<ll>;
using vpii = vector<pii>;

#define all(x) (x).begin(), (x).end()
#define rall(x) (x).rbegin(), (x).rend()
#define sz(x) ((int)((x).size()))
#define F first
#define S second
#define pb push_back
#define mp make_pair
#define lb lower_bound
#define ub upper_bound

#ifndef ONLINE_JUDGE
template<typename A, typename B>

    return os << "{" << p.first << ", " << p.second << "}";
}

    for (size_t i = 0; i < v.size(); ++i) {
        os << v[i];
        if (i != v.size() - 1) os << ", ";
    }
    return os << "]";
}

#define debug(...) cerr << "[DEBUG] " << #__VA_ARGS__ << ": ", DBG(__VA_ARGS__)
template<typename T> void DBG(const T& v) { cerr << v << '\n'; }
template<typename T, typename... Args> void DBG(const T& v, const Args&... args) { cerr << v << ", "; DBG(args...); }
#else
#define debug(...)

using ull = unsigned long long;

struct Item {
    int w;
    int rid;
    int take;
};

vi spf;

inline bool bit_get(const vector<ull>& b, int pos) {
    return (b[pos >> 6] >> (pos & 63)) & 1ULL;
}

void shl_bits(const vector<ull>& src, vector<ull>& dst, int sh) {
    int w = sz(src);
    fill(all(dst), 0ULL);
    int ws = sh >> 6;
    int bs = sh & 63;
    for (int i = w - 1; i >= 0; --i) {
        ull v = 0;
        int j = i - ws;
        if (j >= 0) {
            v |= (src[j] << bs);
            if (bs && j - 1 >= 0) v |= (src[j - 1] >> (64 - bs));
        }
        dst[i] = v;
    }
}

void shr_bits(const vector<ull>& src, vector<ull>& dst, int sh) {
    int w = sz(src);
    fill(all(dst), 0ULL);
    int ws = sh >> 6;
    int bs = sh & 63;
    for (int i = 0; i < w; ++i) {
        ull v = 0;
        int j = i + ws;
        if (j < w) {
            v |= (src[j] >> bs);
            if (bs && j + 1 < w) v |= (src[j + 1] << (64 - bs));
        }
        dst[i] = v;
    }
}

void rotl_bits(const vector<ull>& src, vector<ull>& dst, int d, int nbits, ull last_mask, vector<ull>& t1, vector<ull>& t2) {
    if (d == 0) {
        dst = src;
        return;
    }
    shl_bits(src, t1, d);
    shr_bits(src, t2, nbits - d);
    int w = sz(src);
    for (int i = 0; i < w; ++i) dst[i] = t1[i] | t2[i];
    dst.back() &= last_mask;
}

int critical_num(int p) {
    ll lim = 4LL * (p - 2);
    int x = (int)sqrt((long double)lim);
    while (1LL * (x + 1) * (x + 1) <= lim) ++x;
    while (1LL * x * x > lim) --x;
    return x;
}

bool subset_mod_dp(int p, const vector<Item>& items, int target, vector<int>& take_ids) {
    take_ids.clear();
    if (target == 0) return true;

    int w = (p + 63) >> 6;
    ull last_mask = (p & 63) ? ((1ULL << (p & 63)) - 1ULL) : ~0ULL;

    vector<ull> reach(w, 0ULL), rot(w), t1(w), t2(w);
    reach[0] |= 1ULL;

    vi par_item(p, -1), par_prev(p, -1);

    for (int i = 0; i < sz(items); ++i) {
        int d = items[i].w;
        rotl_bits(reach, rot, d, p, last_mask, t1, t2);

        for (int j = 0; j < w; ++j) {
            ull nw = rot[j] & ~reach[j];
            ull x = nw;
            while (x) {
                int b = __builtin_ctzll(x);
                int r = (j << 6) + b;
                if (r < p) {
                    par_item[r] = i;
                    int pre = r - d;
                    if (pre < 0) pre += p;
                    par_prev[r] = pre;
                }
                x &= x - 1;
            }
            reach[j] |= rot[j];
        }

        if (bit_get(reach, target)) break;
    }

    if (!bit_get(reach, target)) return false;

    int cur = target;
    while (cur != 0) {
        int id = par_item[cur];
        if (id < 0) return false;
        take_ids.pb(id);
        cur = par_prev[cur];
    }
    return true;
}

vi solve_rec(int n, const vi& a);

vi solve_prime(int p, const vi& a) {
    int m = 2 * p - 1;
    vector<pair<int, int>> s;
    s.reserve(m);
    for (int i = 0; i < m; ++i) s.pb({a[i], i});
    sort(all(s));

    for (int i = 0; i < p; ++i) {
        if (s[i].F == s[i + p - 1].F) {
            vi res;
            res.reserve(p);
            for (int j = i; j <= i + p - 1; ++j) res.pb(s[j].S);
            return res;
        }
    }

    int base = s[0].F;
    vi diff(p - 1);
    for (int j = 1; j < p; ++j) {
        base += s[j].F;
        if (base >= p) base %= p;
        diff[j - 1] = s[j + p - 1].F - s[j].F;
    }
    int target = (p - base) % p;

    vi cnt(p, 0), id(p, -1), residues;
    residues.reserve(p - 1);
    for (int d : diff) {
        if (cnt[d] == 0) residues.pb(d);
        cnt[d]++;
    }

    int k = sz(residues);
    for (int i = 0; i < k; ++i) id[residues[i]] = i;

    vector<vi> pos(k);
    for (int i = 0; i < p - 1; ++i) pos[id[diff[i]]].pb(i);

    vector<Item> items;
    items.reserve(p - 1);

    int cr = critical_num(p);

    if (k >= cr) {
        for (int i = 0; i < cr; ++i) {
            int r = residues[i];
            items.pb({r, i, 1});
        }
    } else {
        for (int i = 0; i < k; ++i) {
            int r = residues[i];
            int c = cnt[r];
            int pw = 1;
            while (c > 0) {
                int t = min(pw, c);
                int w = (int)((1LL * r * t) % p);
                items.pb({w, i, t});
                c -= t;
                pw <<= 1;
            }
        }
    }

    vector<int> take_ids;
    if (!subset_mod_dp(p, items, target, take_ids)) {
        debug(p, target, k, cr);
        return {};
    }

    vi pick_cnt(k, 0);
    for (int idd : take_ids) {
        const auto& it = items[idd];
        pick_cnt[it.rid] += it.take;
    }

    vector<char> sw(p - 1, 0);
    for (int i = 0; i < k; ++i) {
        int need = pick_cnt[i];
        if (need > sz(pos[i])) {
            debug(i, need, sz(pos[i]));
            return {};
        }
        for (int j = 0; j < need; ++j) sw[pos[i][j]] = 1;
    }

    vi res;
    res.reserve(p);
    res.pb(s[0].S);
    for (int j = 1; j < p; ++j) {
        if (sw[j - 1]) res.pb(s[j + p - 1].S);
        else res.pb(s[j].S);
    }
    return res;
}

vi solve_rec(int n, const vi& a) {
    if (n == 1) return {0};
    if (n == 2) {
        for (int i = 0; i < 3; ++i) {
            for (int j = i + 1; j < 3; ++j) {
                if (((a[i] + a[j]) & 1) == 0) return {i, j};
            }
        }
        return {};
    }

    if (spf[n] == n) return solve_prime(n, a);

    int x = spf[n];
    int y = n / x;

    deque<int> pool;
    for (int i = 0; i < sz(a); ++i) pool.pb(i);

    int k = 2 * x - 1;
    int gsz = 2 * y - 1;
    vector<int> flat(gsz * x);
    vi carry;
    carry.reserve(gsz);

    for (int it = 0; it < gsz; ++it) {
        vi pack(k), small(k);
        for (int i = 0; i < k; ++i) {
            pack[i] = pool.front();
            pool.pop_front();
            small[i] = a[pack[i]] % x;
        }

        vi pick = solve_rec(x, small);
        if (sz(pick) != x) {
            debug(n, x, y);
            return {};
        }

        vector<char> mk(k, 0);
        for (int idd : pick) mk[idd] = 1;

        vi keep;
        keep.reserve(x - 1);
        ll s = 0;
        int ptr = 0;

        for (int i = 0; i < k; ++i) {
            if (mk[i]) {
                flat[it * x + ptr] = pack[i];
                ptr++;
                s += a[pack[i]];
            } else {
                keep.pb(pack[i]);
            }
        }

        for (int i = sz(keep) - 1; i >= 0; --i) pool.push_front(keep[i]);
        carry.pb((int)((s / x) % y));
    }

    vi take_group = solve_rec(y, carry);
    if (sz(take_group) != y) return {};

    vi ans;
    ans.reserve(n);
    for (int g : take_group) {
        int st = g * x;
        for (int i = 0; i < x; ++i) ans.pb(flat[st + i]);
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;
    vi a(2 * n - 1);
    for (int i = 0; i < 2 * n - 1; ++i) cin >> a[i];

    spf.assign(n + 1, 0);
    for (int i = 0; i <= n; ++i) spf[i] = i;
    for (int i = 2; 1LL * i * i <= n; ++i) {
        if (spf[i] != i) continue;
        for (int j = i * i; j <= n; j += i) {
            if (spf[j] == j) spf[j] = i;
        }
    }

    vi pick = solve_rec(n, a);

    if (sz(pick) != n) {
        cout << -1 << '\n';
        return 0;
    }

    for (int i = 0; i < n; ++i) {
        if (i) cout << ' ';
        cout << a[pick[i]];
    }
    cout << '\n';

    return 0;
}

## 검증

### 시간복잡도

- 소수 p 케이스: O(p * m / 64)
    - m=C=floor(2*sqrt(p-2)) 또는 m=O(D log p)
- 합성수 재귀 오버헤드는 선형 계열이고, 전체 병목은 가장 큰 소수 하위문제
- N=500000에서도 실측 기준 충분히 빠르게 동작한다.

### 공간복잡도

- O(N)
- 비트셋 O(p/64), parent O(p), 재귀 버퍼 포함

### 코너 케이스

- N=1, N=2 베이스 케이스
- 소수에서 빠른 종료 구간(x_i==x_{i+p-1})
- D가 매우 작은 경우(중복 많은 입력): bounded 분기
- D가 큰 경우(거의 전부 다른 값): critical 분기

### 테스트 체크

- N=4, a=[1,2,3,0,1,2,3] -> 길이 4 출력, 합 %4==0
- N=500000, 랜덤 입력 -> 길이 500000 출력, 합 %500000==0
