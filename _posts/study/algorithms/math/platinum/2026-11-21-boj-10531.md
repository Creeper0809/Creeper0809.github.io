## 문제 해석

- 로봇이 칠 수 있는 비거리가 N개 주어진다
- 로봇이 한번 또는 두번 쳐서 주어진 M개의 골대 중 몇개에 정확히 넣을 수 있는가?

## 문제 태그

- 정수론
- fft

## 아이디어

1. 우리가 필요한 것은 한 번 또는 두 번 친 값이 필요한데, 이는 컨볼루션 연산과 같다. 각 비거리를 x의 지수로 생각하면 그 수의 존재 여부를 알 수 있다.
    1. $$A(x) = x^2 + x^3 + x^5$$
    2. $$A(x)^2 = x^4+2x^5+x^6+2x^7+2x^8+x^{10}$$
    
    만약 골대의 거리가 이 지수에 해당하는 인덱스에 존재한다면 그렇게 칠 수 있는 방법이 존재한다는 것이다.
    

## 정답

```python
MOD = 998244353
PRIMITIVE_ROOT = 3

def ntt(a, invert):
    n = len(a)
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]

    length = 2
    while length <= n:
        wlen = pow(PRIMITIVE_ROOT, (MOD - 1) // length, MOD)
        if invert:
            wlen = pow(wlen, MOD - 2, MOD)
        for i in range(0, n, length):
            w = 1
            for j in range(length // 2):
                u = a[i + j]
                v = a[i + j + length // 2] * w % MOD
                a[i + j] = (u + v) % MOD
                a[i + j + length // 2] = (u - v + MOD) % MOD
                w = w * wlen % MOD
        length <<= 1

    if invert:
        inv_n = pow(n, MOD - 2, MOD)
        for i in range(n):
            a[i] = a[i] * inv_n % MOD

def ntt_convolution(a, b):
    n = 1
    while n < len(a) + len(b):
        n <<= 1
    a += [0] * (n - len(a))
    b += [0] * (n - len(b))

    ntt(a, False)
    ntt(b, False)
    for i in range(n):
        a[i] = a[i] * b[i] % MOD
    ntt(a, True)
    return a

N = int(input())
a = [int(input()) for _ in range(N)]
size = (max(a)+1)
a_count = [0] * size

for i in a:
    a_count[i] += 1

c = ntt_convolution(a_count[:], a_count[:])
M = int(input())
answer = 0
for _ in range(M):
    number = int(input())
    if (len(c) > number and c[number] > 0) or (size > number and a_count[number] > 0):
        answer += 1
print(answer)
```
