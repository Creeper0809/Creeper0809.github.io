## 문제 태그

- 기하학
- 스위핑
- 분할 정복

## 아이디어

1. **초기 x 정렬으로 분할 기준을 마련**
    - 전체 점 집합을 한 번만 x 좌표 기준으로 오름차순 정렬하는 것이다.
    - 이렇게 해 두면, 이후 재귀 분할 시 "왼쪽 절반"과 "오른쪽 절반"을 단순히 인덱스 절단(mid)으로 나눌 수 있다.
    - 즉, 매번 정렬 비용을 들이지 않고도 x 기준으로 균형 잡힌 분할이 보장된다.
2. **재귀 호출 시 구간별 y 정렬 결과를 함께 반환해 병합에 재사용**
    - 각 구간(L ~ R)에 대해 최단거리 계산과 동시에, 그 구간의 점들을 **y 기준으로 정렬된 리스트**로 반환한다.
    - 상위 호출에서는 이 두 개의 y정렬 리스트를 "병합 정렬" 방식(O(n))으로 합쳐 전체 구간을 y 기준으로 정렬한다.
    - 이렇게 하면 중간 병합(스트립 검사 전 단계)에서 추가 정렬 비용이 전혀 들지 않고, 전체 알고리즘이 O(n log n)을 유지할 수 있다.
3. **스위핑 스트립: 분할 경계에서** $$\sqrt{d}$$ **이내의 점만 검사**
    - 좌우 하위 결과에서 얻은 최단거리 제곱 d를 기준으로, 분할 축 $$x = mid_x$$ 근처에만 주의를 기울인다.
    - 구간 전체 점 중 $$(x - mid_x)^2 < d$$를 만족하는 점들만 "스트립(strip)" 리스트에 모으는데, 이 리스트는 이미 y 기준으로 정렬되어 있다.
    - 이유는, 하위 구간들에서 이미 "두 점이 d보다 멀면 더 이상 고려할 필요가 없다"는 걸 증명했기 때문에, 경계 근처 $$\sqrt{d}$$ 바깥 점 간에는 더 짧은 쌍이 있을 수 없기 때문이다.
4. **상수 개수만 검사 (최대 7개) → 전체가 O(n log n)**
    - y 기준으로 정렬된 스트립에서, 각 점마다 **다음 6개 이내**의 점만 비교하면 충분하다는 수학적 정리가 있다.
    - 따라서 이중 루프가 겉보기에는 $$O(k^2)$$ 같지만, 실제로는 각 점당 최대 6회 비교만 발생 → 전체 스트립 검사가 O(n)이다.
    - 이로써 분할정복의 점 분할 비용 2T(n/2)와 병합·스트립 검사 비용 O(n)를 합해
        
        $$
        T(n) = 2T(\tfrac{n}{2}) + O(n) \quad\Longrightarrow\quad T(n)=O(n\log n)
        $$
        

## 정답

```python
import sys
sys.setrecursionlimit(10 ** 7)
input = sys.stdin.readline

def divide_merge(pts):
    n = len(pts)
    if n <= 3:
        min_d = float('inf')
        for i in range(n):
            for j in range(i + 1, n):
                dx = pts[i][0] - pts[j][0]
                dy = pts[i][1] - pts[j][1]
                min_d = min(min_d, dx * dx + dy * dy)
        pts.sort(key=lambda p: p[1])
        return min_d, pts
    mid = n // 2
    mid_x = pts[mid][0]
    dl, left_sorted_by_y = divide_merge(pts[:mid])
    dr, right_sorted_by_y = divide_merge(pts[mid:])
    d = min(dl, dr)
    merged = []
    i = j = 0
    L, R = left_sorted_by_y, right_sorted_by_y
    while i < len(L) and j < len(R):
        if L[i][1] < R[j][1]:
            merged.append(L[i])
            i += 1
        else:
            merged.append(R[j])
            j += 1
    merged.extend(L[i:])
    merged.extend(R[j:])
    strip = [p for p in merged if (p[0] - mid_x) ** 2 < d]
    m = len(strip)
    for i in range(m):
        for j in range(i + 1, min(i + 7, m)):
            dx = strip[i][0] - strip[j][0]
            dy = strip[i][1] - strip[j][1]
            dist = dx * dx + dy * dy
            if dist < d:
                d = dist
    return d, merged

n = int(input())
points = [tuple(map(int, input().split())) for _ in range(n)]
points.sort()
distance, _ = divide_merge(points)
print(distance)

```
