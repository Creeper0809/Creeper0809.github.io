## 문제 태그

- 뤼카 정리

## 아이디어

1. N,K의 범위도 크고 M이 < 2000 이하라 페르마의 소정리로 구하는 알고리즘에서는 사용할 수 없다
2. N,K의 범위도 크고 M이 소수로 정해져있어 사용할 수 있는 방법이 뤼카 정리이다
3. 간단하게 말하면 nCr mod p에서 n,c를 p진수로 변환하고 각 자리수에 맞게 조합을 구하면 된다
    1. 예시) 30C3 mod 3
    
    | 30 | 1 | 0 | 1 | 0 |
    | --- | --- | --- | --- | --- |
    | 3 | 0 | 0 | 1 | 0 |

$$
30C3 \ mod \ 3 = \binom{1}{0} * \binom{0}{0} * \binom{1}{1} *\binom{0}{0}\ mod \ 3 = 1
$$

고로 30C3 mod 3 = 1

## 정답

```python
import sys
input = sys.stdin.readline

def power(x:int, y:int,m):
    res = 1
    x = x % m
    while y > 0:
        if y & 1:  # y가 홀수면
            res = res * x % m # x와 곱하고 나머지 연산
        # y가 짝수이면
        y = y >> 1  # y /= 2
        x = (x * x) % m  # 거듭제곱 계산
    return res

def ncr(n, r, m):
    facterial = [1] * (m)
    for i in range(1,m):
        facterial[i] = (i * facterial[i-1]) % m
    return (facterial[n] * power(facterial[r] * facterial[n-r],m-2,m)) % m

def lucas(n, r, p):
    if r > n:
        return 0
    result = 1
    while n or r:
        ni = n % p
        ri = r % p
        if ri > ni:
            return 0
        result = result * ncr(ni, ri, p) % p
        n //= p
        r //= p
    return result

n,r,m = map(int,input().split())
print(lucas(n,r,m))

```
