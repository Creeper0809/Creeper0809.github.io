## 1. 개요

Coppersmith Attack은 RSA 암호 시스템에서 특정 조건 하에 모듈러 다항식의 작은 근을 효율적으로 찾아내는 강력한 공격 기법이다. 1996년 Don Coppersmith가 제안한 이 방법은 RSA의 보안성이 단순히 큰 합성수 $$N$$의 소인수분해 난이도에만 의존하지 않음을 보여주었다.

## 2. Coppersmith 정리

Coppersmith 정리는 모듈러 다항식 방정식에서 특정 범위 내의 작은 근을 다항 시간 내에 찾을 수 있음을 보장하는 강력한 이론적 도구이다. 이 정리는 LLL 격자 기저 축약 알고리즘을 핵심 기법으로 활용한다.

## 2.1 문제 정의

주어진 모듈러 다항식 방정식에서 작은 정수해를 찾는 문제를 정의한다.

### 2.1.1 기본 설정

<aside class="notion-callout notion-callout--with-icon" markdown="1">
💡
{: .notion-callout__icon aria-hidden="true"}

**모닉 다항식**

최고차 항의 계수가 1인 다항식을 의미한다.

예를 들어, $$f(x) = x^3 + 2x^2 - 5x + 7$$은 모닉 다항식이다 (최고차 항 $$x^3$$의 계수가 1).

반면 $$g(x) = 3x^3 + 2x^2 - 5x + 7$$은 모닉 다항식이 아니다 (최고차 항의 계수가 3).

</aside>

- **입력:** $$d$$차 모닉 다항식 $$f(x)$$, 합성수 $$N$$
- **목표:** $$f(x_0) \equiv 0 \pmod{N}$$을 만족하는 작은 정수 $$x_0$$ 찾기
- **모닉 다항식:** 최고차 항의 계수가 1인 다항식, 즉 $$f(x) = x^d + a_{d-1}x^{d-1} + \cdots + a_1 x + a_0$$

### 2.1.2 문제의 난이도

**무작위 대입의 비효율성**

- $$x_0$$의 탐색 공간이 $$[-X, X]$$라면, 무작위 대입은 $$O(X)$$ 시간이 필요
- $$X$$가 충분히 크면 (예: $$X \approx N^{1/d}$$) 계산적으로 불가능

**소인수분해와의 관계**

- 일반적인 경우, 이 문제는 $$N$$의 소인수분해만큼 어려울 수 있음
- 하지만 $$x_0$$가 충분히 작으면, 소인수분해 없이도 해를 찾을 수 있음

## 2.2 정리의 핵심 내용

<aside class="notion-callout" markdown="1">

**Coppersmith 정리:**

$$f(x)$$가 $$d$$차 모닉 다항식이고, $$N$$이 충분히 큰 합성수일 때,

$$
\vert x_0\vert  < N^{1/d - \epsilon}
$$

범위 내의 모든 해 $$x_0$$는 다항 시간 내에 찾을 수 있다. (여기서 $$\epsilon > 0$$는 임의의 작은 양수)

</aside>

### 2.2.1 정리의 의미

**작은 해의 기준**

- 해가 "작다"는 것은 $$N^{1/d}$$보다 작은 규모를 의미
- 예: $$N = 10^{100}$$, $$d = 3$$이면 $$x_0 < 10^{33}$$ 정도의 해를 찾을 수 있음
- $$\epsilon$$은 이론적 여유 공간으로, 실제로는 매우 작은 값 (예: 0.01)

**정수 해로의 환원**

- Coppersmith 방법은 모듈러 방정식 $$f(x) \equiv 0 \pmod{N}$$의 해를 정수 방정식 $$g(x) = 0$$ (일반 정수 상에서)의 해로 변환
- $$g(x)$$는 $$f(x)$$와 관련된 다항식으로, LLL 알고리즘을 통해 구성됨
- 변환된 정수 방정식은 표준 근의 공식이나 수치적 방법으로 풀 수 있음

### 2.2.2 알고리즘의 복잡도

**시간 복잡도**

- LLL 알고리즘 실행: $$O(d^6 \log^3 N)$$
- 다항식 근 찾기: $$O(d^3)$$
- 전체: 다항 시간

**공간 복잡도**

- 격자 차원: $$O(d^2)$$
- 각 벡터의 길이: $$O(\log N)$$ 비트

### 2.2.3 정리의 한계

- **해의 크기 제약:** $$x_0 \geq N^{1/d}$$이면 이론적 보장이 없음. 실제로도 성공률이 급격히 떨어짐
- **모닉 다항식 가정:** 최고차 계수가 1이 아니면 변환 과정이 필요. 하지만 대부분의 경우 변수 치환으로 해결 가능
- **다항식 차수:** $$d$$가 클수록 찾을 수 있는 해의 범위가 줄어듦. $$d = 1$$일 때 $$N$$까지, $$d = 2$$일 때 $$N^{1/2}$$까지

## 2.3 Howgrave-Graham의 접근법

1997년 Nick Howgrave-Graham은 Coppersmith의 원래 증명을 더 직관적이고 구현하기 쉬운 형태로 재구성했다. 현재 대부분의 구현은 이 접근법을 따른다.

### 2.3.1 핵심 보조정리

<aside class="notion-callout" markdown="1">

**보조정리:**

$$h(x)$$가 최대 $$d$$개의 단항식을 가진 정수 계수 다항식이고, 다음 두 조건을 만족한다고 하자:

1. $$h(x_0) \equiv 0 \pmod{N^m}$$ (어떤 작은 정수 $$x_0$$, $$\vert x_0\vert  < X$$)
2. $$\|h(xX)\| < N^m / \sqrt{d}$$ (다항식의 계수 노름)

그러면 $$h(x_0) = 0$$이 정수 상에서 성립한다

</aside>

### 2.3.2 노름의 정의

다항식 $$h(x) = \sum_{i=0}^{d} a_i x^i$$에 대해:

$$
\|h(xX)\| = \sqrt{\sum_{i=0}^{d} (a_i X^i)^2}
$$

**의미:**

- 각 계수 $$a_i$$를 $$X^i$$로 스케일링한 후의 유클리드 노름
- $$x_0 \approx X$$일 때 다항식 값의 크기를 대략적으로 나타냄
- 노름이 작다 = 모든 계수가 작다 = 작은 $$x$$에서 작은 값

### 2.3.3 증명 스케치

**1단계: 모듈러 조건**

가정에 의해 $$h(x_0) \equiv 0 \pmod{N^m}$$이므로, 어떤 정수 $$k$$에 대해:

$$
h(x_0) = k \cdot N^m
$$

**2단계: 크기 추정**

삼각 부등식과 $$\vert x_0\vert  < X$$를 이용하면:

$$
\vert h(x_0)\vert  \leq \|h(xX)\| \cdot \sqrt{d}
$$

**3단계: 노름 조건 적용**

가정 (2)에서 $$\|h(xX)\| < N^m / \sqrt{d}$$이므로:

$$
\vert h(x_0)\vert  < N^m
$$

**4단계: 결론**

$$\vert k \cdot N^m\vert  < N^m$$이므로 $$\vert k\vert  < 1$$. $$k$$는 정수이므로 $$k = 0$$, 즉 $$h(x_0) = 0$$.

### 2.3.4 알고리즘 전략

Howgrave-Graham의 접근법은 다음 전략을 제시한다:

1. **격자 구성:** $$f(x), xf(x), x^2f(x), \ldots$$ 및 $$N, Nx, Nx^2, \ldots$$ 등을 이용하여 다항식들의 격자를 만듦
2. **LLL 적용:** 이 격자에 LLL 알고리즘을 적용하여 노름이 작은 다항식 $$h(x)$$ 찾기
3. **근 계산:** $$h(x) = 0$$을 정수 상에서 풀어 $$x_0$$ 획득
4. **검증:** $$f(x_0) \equiv 0 \pmod{N}$$ 확인

이 방법의 장점은 복잡한 이론 없이도 구현 가능하며, 파라미터 튜닝($$m$$, $$X$$ 선택)이 명확하다는 것이다.

### 2.3.5 실용적 고려사항

**파라미터 선택**

- $$m$$ (Hensel lifting 횟수): 보통 $$m = \lceil \frac{d}{\epsilon} \rceil$$로 선택
- $$X$$ (해의 상한): 이론적으로는 $$N^{1/d - \epsilon}$$, 실제로는 약간 크게 설정하여 성공률 향상

**수치적 안정성**

- LLL 알고리즘 구현 시 부동소수점 오차 주의
- SageMath의 small_roots() 메서드는 이러한 문제를 자동으로 처리

**성능 최적화**

- 격자 차원 최소화를 위해 불필요한 다항식 제거
- 병렬 LLL 알고리즘 활용 가능
