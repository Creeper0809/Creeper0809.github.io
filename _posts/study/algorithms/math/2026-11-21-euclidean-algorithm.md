## 설명

유클리드의 호제법은 두 수의 최대공약수를 구하는 알고리즘이다.

예를 들어, 24와 36의 최대공약수를 구하는 과정은 다음과 같다.

1. 36을 24로 나눈다.
2. 나머지가 12이므로, 24를 12로 나눈다.
3. 나머지가 0이므로, 12가 최대공약수이다.

이를 수식으로 표현하면 다음과 같다.

$$
gcd(24, 36) = gcd(36 \div 24, 24) = gcd(12, 24 \div 12) = gcd(12, 0) = 12
$$

파이썬으로 구현하면 다음과 같다.

```
def gcd(a, b):
    if b == 0:
        return a
    return gcd(b, a % b)
```

위의 예제에서 gcd(24, 36)을 구하는 코드는 다음과 같다.

```
print(gcd(24, 36)) # Output: 12
```

두 수의 최소공배수(LCM)와 최대공약수(GCD)는 다음 관계가 성립한다: m × n = GCD × LCM.

따라서 GCD를 구한 후, 두 수의 곱을 GCD로 나누면 최소공배수를 얻을 수 있다.

## 증명

유클리드 호제법의 증명은 다음과 같다

- 두 양의 정수 a와 b (a > b)가 있을 때, a = bq + r (0 ≤ r < b)로 표현할 수 있다.
    - 여기서 q는 몫이고 r은 나머지이다.
- a와 b의 공약수 d를 생각해보자
    - d는 a와 b를 모두 나눌 수 있다. (a = dm, b = dn)
    - r = a - bq = dm - dnq = d(m - nq)이므로, d는 r도 나눌 수 있다.
- 따라서 a와 b의 모든 공약수는 b와 r의 공약수이기도 하다.
- 반대로 b와 r의 공약수 e가 있다면 (b = ek, r = el), a = bq + r = ekq + el = e(kq + l)이므로, e는 a도 나눌 수 있다.
- 결론
    - a와 b의 공약수 집합은 b와 r의 공약수 집합과 같다.
    - 즉, gcd(a, b) = gcd(b, r)이 성립한다.
    - 이 과정을 r이 0이 될 때까지 반복하면, 마지막 나누는 수가 a와 b의 최대공약수이다.

## 확장 유클리드 알고리즘

확장 유클리드 알고리즘은 두 정수 a와 b의 최대공약수(gcd)를 구할 뿐만 아니라 베주 항등식을 만족하는 정수 x와 y를 찾는 알고리즘이다.

### 베주 항등식

a, b가 정수이고 d = gcd(a, b)일 때, ax + by = d를 만족하는 정수 x, y가 항상 존재한다는 것이 베주 항등식이다.

</aside>

### 증명

확장 유클리드 알고리즘의 증명은 수학적 귀납법을 사용한다:

- 기본 단계: b = 0인 경우, gcd(a, 0) = a이며 $$a\cdot1 + 0\cdot0 = a$$이므로 x = 1, y = 0으로 베주 항등식이 성립한다.
- 귀납 단계: b > 0인 경우를 가정하자.
    - a = bq + r (0 ≤ r < b)에서 r = a - bq이다.
    - 귀납적으로 gcd(b, r) = bx' + ry'를 만족하는 x', y'가 존재한다고 가정하자.
    - r = a - bq를 대입하면: gcd(a, b) = bx' + (a - bq)y' = ay' + b(x' - qy')
    - 따라서 x = y'와 y = x' - qy'로 놓으면 ax + by = gcd(a, b)가 성립한다.

### 알고리즘 원리

유클리드 호제법의 과정을 역추적하여 x와 y를 구한다.

기본 아이디어는 다음과 같다:

- gcd(a, b) = gcd(b, a % b)임을 이용해 재귀적으로 계산한다.
- 각 단계에서 ax + by = gcd(a, b)를 만족하는 x, y를 찾는다.

### 구현

```python
def extended_gcd(a, b):
    if a == 0:
        return b, 0, 1
    else:
        gcd, x1, y1 = extended_gcd(b % a, a)
        x = y1 - (b // a) * x1
        y = x1
        return gcd, x, y

```

### 예시

a = 35, b = 15를 예시로 확장 유클리드 알고리즘을 적용해보자.

| 단계 | a | b | q (b÷a) | r (b%a) | x | y | 식 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 35 | 15 | - | - | - | - | - |
| 2 | 15 | 5 | 2 | 5 | - | - | - |
| 3 | 5 | 0 | - | 0 | 1 | 0 | 5·1 + 0·0 = 5 |
| 2(역) | 15 | 5 | - | - | 0 | 1 | 15·0 + 5·1 = 5 |
| 1(역) | 35 | 15 | - | - | -2 | 1 | 35·(-2) + 15·1 = 5 |

```
extended_gcd(35, 15):
  step 1: extended_gcd(15, 5)
    step 1.1: extended_gcd(5, 0)
      → 반환: (5, 0, 1) # gcd=5, x=0, y=1
    → 계산: x = 1 - (15 // 5) * 0 = 1
           y = 0
    → 반환: (5, 1, 0) # gcd=5, x=1, y=0
  → 계산: x = 0 - (35 // 15) * 1 = -2
         y = 1
  → 반환: (5, -2, 1) # gcd=5, x=-2, y=1

```

따라서 35 * (-2) + 15 * 1 = -70 + 15 = -55 = -5 * 11 = -5 * 11 + 5 * 12 = 5 * (12 - 11) = 5 * 1 = 5가 된다.

이는 gcd(35, 15) = 5를 확인할 수 있으며, 35 * (-2) + 15 * 1 = 5라는 베주 항등식이 성립함을 보여준다.

### 추가 예시

a = 48, b = 18의 경우를 단계별로 살펴보자:

| 단계 | a | b | q (a÷b) | r (a%b) | x | y | 베주 항등식 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 48 | 18 | 2 | 12 | - | - | - |
| 2 | 18 | 12 | 1 | 6 | - | - | - |
| 3 | 12 | 6 | 2 | 0 | - | - | - |
| 4 | 6 | 0 | - | - | 1 | 0 | 6·1 + 0·0 = 6 |
| 3(역) | 12 | 6 | - | - | 0 | 1 | 12·0 + 6·1 = 6 |
| 2(역) | 18 | 12 | - | - | 1 | -1 | 18·1 + 12·(-1) = 6 |
| 1(역) | 48 | 18 | - | - | -1 | 3 | 48·(-1) + 18·3 = 6 |

따라서 gcd(48, 18) = 6이며, 48·(-1) + 18·3 = 6이라는 베주 항등식이 성립한다.

### 활용

- 모듈러 역원 계산: a가 n과 서로소일 때, ax ≡ 1 (mod n)을 만족하는 x를 구할 수 있다.
- 디오판토스 방정식 해결: ax + by = c 형태의 방정식 해결에 활용된다.
- RSA 암호화 알고리즘에서 개인키 생성에 사용된다.
- 중국인의 나머지 정리 구현에 활용된다.
