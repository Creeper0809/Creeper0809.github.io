## 문제 태그

- 그래프
- 너비 우선 탐색
- 최단거리

## 문제 요약

### 입력

- 사람 수 N, 친구 관계 수 M이 주어진다.
- 이후 M줄에 친구 관계 A, B가 주어진다.

### 출력

- 케빈 베이컨 수가 가장 작은 사람 번호를 출력한다.
- 같은 값이면 번호가 더 작은 사람을 출력한다.

### 제약

- 2 ≤ N ≤ 100
- 1 ≤ M ≤ 5000
- 그래프는 연결 그래프다.

### 목표 재정의

- 각 사람을 시작점으로 다른 모든 사람까지의 최단거리 합을 구하고, 그 합이 최소인 정점을 찾는다.

## 예시 워크스루

- 예시 입력
    - N=5, M=5
    - 간선: (1,3), (1,4), (4,5), (4,3), (3,2)
1. 그래프를 인접 리스트로 만든다.
2. 시작점 1에서 너비 우선 탐색을 돌리면 거리 배열은 다음과 같다.
    - 1→1:0, 1→3:1, 1→4:1, 1→2:2, 1→5:2
    - 합은 6이다.
3. 시작점 3에서 너비 우선 탐색을 돌리면 거리 배열은 다음과 같다.
    - 3→1:1, 3→2:1, 3→4:1, 3→5:2
    - 합은 5다.
4. 시작점 4의 합도 5다.
5. 최소 합은 5이고 후보는 3, 4다. 번호가 작은 3을 정답으로 선택한다.

## 아이디어

### 핵심 관찰

- 모든 간선 가중치가 1이므로 한 시작점에서의 최단거리는 너비 우선 탐색으로 구할 수 있다.
- 문제에서 요구하는 케빈 베이컨 수는 시작점 하나에서 모든 정점까지 최단거리 합이다.
- N이 100이므로 모든 정점을 시작점으로 탐색해도 충분히 빠르다.

### 알고리즘 설계

1. 인접 리스트를 구성한다.
2. 시작점 st를 1부터 N까지 순회한다.
3. st에서 너비 우선 탐색을 수행해 dist를 구한다.
4. dist 합을 계산해 현재 최소값과 비교한다.
5. 더 작으면 정답 후보를 갱신한다.
6. 같으면 갱신하지 않는다. 순회를 작은 번호부터 하므로 자동으로 작은 번호가 유지된다.

### 정당성 요약

- 너비 우선 탐색은 무가중치 그래프에서 시작점으로부터 각 정점까지의 최단거리 레벨을 정확히 계산한다.
- 따라서 각 시작점에서 구한 거리 합은 해당 사람의 케빈 베이컨 수와 같다.
- 모든 사람을 시작점으로 검사하므로 전역 최솟값을 놓치지 않는다.
- 동률일 때 작은 번호를 유지하는 규칙도 순회 순서와 갱신 조건으로 만족한다.

## 구현 포인트

### 자료구조 선택

- 인접 리스트 vector<vector<int>>를 사용한다.
- 거리 배열 dist와 큐 queue<int>로 너비 우선 탐색을 구현한다.

### 인덱싱과 경계

- 사람 번호가 1부터 N이므로 1 기반 인덱싱을 그대로 사용한다.
- dist 초기값은 -1로 두고 첫 방문 시 거리 확정한다.

### 실수 포인트

- 간선 중복 입력이 있어도 dist 방문 체크가 있으므로 결과는 변하지 않는다.
- 연결 그래프 조건 때문에 최종 dist에 -1이 남지 않는다.

## 정답

```cpp
#include <bits/stdc++.h>

using namespace std;

using ll = long long;
using pii = pair<int, int>;
using vi = vector<int>;
using vll = vector<ll>;
using vpii = vector<pii>;

#define all(x) (x).begin(), (x).end()
#define rall(x) (x).rbegin(), (x).rend()
#define sz(x) ((int)((x).size()))
#define F first
#define S second
#define pb push_back
#define mp make_pair
#define lb lower_bound
#define ub upper_bound

#ifndef ONLINE_JUDGE
template<typename A, typename B>
ostream& operator<<(ostream& os, const pair<A, B>& p) {
    return os << "{" << p.first << ", " << p.second << "}";
}
template<typename T>
ostream& operator<<(ostream& os, const vector<T>& v) {
    os << "[";
    for (size_t i = 0; i < v.size(); ++i) {
        os << v[i];
        if (i != v.size() - 1) os << ", ";
    }
    return os << "]";
}

#define debug(...) cerr << "[DEBUG] " << #__VA_ARGS__ << ": ", DBG(__VA_ARGS__)
template<typename T> void DBG(const T& v) { cerr << v << endl; }
template<typename T, typename... Args> void DBG(const T& v, const Args&... args) { cerr << v << ", "; DBG(args...); }
#else
#define debug(...)
#endif

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    
    int n, m;
    cin >> n >> m;

    vector<vi> adj(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].pb(v);
        adj[v].pb(u);
    }

    ll best = (ll)4e18;
    int ans = 1;

    for (int st = 1; st <= n; st++) {
        vi dist(n + 1, -1);
        queue<int> q;
        q.push(st);
        dist[st] = 0;

        while (!q.empty()) {
            int cur = q.front();
            q.pop();

            for (int nxt : adj[cur]) {
                if (dist[nxt] != -1) continue;
                dist[nxt] = dist[cur] + 1;
                q.push(nxt);
            }
        }

        ll cur = 0;
        for (int i = 1; i <= n; i++) cur += dist[i];

        debug(st, cur);

        if (cur < best) {
            best = cur;
            ans = st;
        }
    }

    cout << ans << '\n';
    
    return 0;
}
```

## 검증

### 시간복잡도

- O(N(N+M))
- N=100, M=5000일 때 최대 연산량은 충분히 제한 이내다.

### 공간복잡도

- O(N+M)
- 인접 리스트와 탐색용 배열만 사용하므로 메모리 제한 이내다.

### 코너 케이스

- 모든 정점이 한 정점과만 연결된 별 모양 그래프
- 길게 이어진 체인 그래프
- 중복 간선이 많은 입력
- 최소 합이 여러 명에게서 같게 나오는 입력
