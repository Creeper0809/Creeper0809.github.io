## 문제 요약

### 입력

- 테스트케이스 수 T가 주어진다.
- 각 테스트케이스마다 건물 수 N, 규칙 수 K가 주어진다.
- 각 건물 건설 시간 D가 주어진다.
- 이후 K줄에 X Y가 주어지며, X를 완료해야 Y를 시작할 수 있다.
- 목표 건물 W가 주어진다.

### 출력

- 건물 W를 가장 빠르게 완성하는 최소 시간을 출력한다.

### 제약

- 2 ≤ N ≤ 1000
- 1 ≤ K ≤ 100000
- 0 ≤ D ≤ 100000
- 모든 건물이 건설 가능하도록 규칙이 주어진다.

### 목표 재정의

- 선행 조건이 있는 건설 그래프에서 목표 건물의 가장 이른 완료 시각을 구한다.

## 예시 워크스루

- 예시 입력
    - N=4, K=4
    - 건설 시간: 1번 10, 2번 1, 3번 100, 4번 10
    - 규칙: 1→2, 1→3, 2→4, 3→4
    - 목표: 4
1. 진입차수는 1번만 0이고, 나머지는 선행 건물이 있다.
2. 초기 큐에 1번을 넣고, 완료 시각 배열을 1번만 10으로 둔다.
3. 1번을 꺼내 2번, 3번을 갱신한다.
    - 2번 완료 시각 = 10 + 1 = 11
    - 3번 완료 시각 = 10 + 100 = 110
4. 2번을 처리하면 4번 후보 완료 시각은 21이 된다. 아직 3번이 남아 4번은 시작할 수 없다.
5. 3번을 처리하면 4번 후보 완료 시각은 max(21, 110 + 10) = 120으로 갱신된다.
6. 이제 4번의 모든 선행 건물이 끝났으므로 4번 확정 완료 시각은 120이다.
7. 목표 건물 4의 최소 완료 시간은 120이다.

## 아이디어

### 핵심 관찰

- 어떤 건물 v는 선행 건물들이 모두 끝난 뒤에만 시작할 수 있다.
- 따라서 v의 시작 시각은 선행 건물 완료 시각들의 최댓값이다.
- 건설 시간 Dv를 더하면 v의 완료 시각이 된다.
- 선행 규칙 그래프는 사이클이 없으므로 위상 정렬 순서로 완료 시각을 확정할 수 있다.

$$
dp[v] = D_v + \max_{u \in pred(v)} dp[u]
$$

- 선행 건물이 없는 경우는 바로 시작 가능하므로 dp[v] = D_v 이다.

### 알고리즘 설계

1. 인접 리스트와 진입차수 배열을 만든다.
2. 진입차수가 0인 건물을 큐에 넣고 dp를 자기 건설 시간으로 초기화한다.
3. 큐에서 건물 cur를 꺼내면서 모든 다음 건물 nxt에 대해
    - dp[nxt] = max(dp[nxt], dp[cur] + D[nxt])
    - 진입차수를 1 감소
    - 진입차수가 0이 되면 큐에 넣는다.
4. 큐 처리가 끝나면 dp[W]가 정답이다.

### 정당성 요약

- 위상 정렬에서 어떤 건물 v가 큐에 들어갈 때는 모든 선행 건물이 이미 처리된 상태다.
- 따라서 그 시점의 dp[v]는 가능한 모든 선행 경로에서의 완료 시각 최대값을 반영한다.
- 이후 v의 값은 더 바뀌지 않으므로 완료 시각이 정확히 확정된다.
- 모든 건물을 이 방식으로 처리하면 목표 건물 W의 최소 완료 시간이 정확히 계산된다.

## 구현 포인트

### 자료구조 선택

- 간선 수가 많으므로 인접 리스트를 사용한다.
- 위상 순서 처리는 queue를 사용한다.
- 완료 시각 누적은 dp 배열로 관리한다.

### 인덱싱과 초기화

- 입력 번호가 1부터 시작하므로 1 기반 배열을 그대로 사용한다.
- 테스트케이스마다 adj, deg, dp를 새로 생성해 상태 오염을 막는다.

### 오버플로우 점검

- 최악 경로 길이는 최대 1000, 건설 시간 최대 100000이다.
- 완료 시각 최대치는 약 100000000이므로 int 범위에서 안전하다.

## 정답

```cpp
#include <bits/stdc++.h>

using namespace std;

using ll = long long;
using pii = pair<int, int>;
using vi = vector<int>;
using vll = vector<ll>;
using vpii = vector<pii>;

#define all(x) (x).begin(), (x).end()
#define rall(x) (x).rbegin(), (x).rend()
#define sz(x) ((int)((x).size()))
#define F first
#define S second
#define pb push_back
#define mp make_pair
#define lb lower_bound
#define ub upper_bound

#ifndef ONLINE_JUDGE
template<typename A, typename B>
ostream& operator<<(ostream& os, const pair<A, B>& p) {
    return os << "{" << p.first << ", " << p.second << "}";
}
template<typename T>
ostream& operator<<(ostream& os, const vector<T>& v) {
    os << "[";
    for (size_t i = 0; i < v.size(); ++i) {
        os << v[i];
        if (i != v.size() - 1) os << ", ";
    }
    return os << "]";
}

#define debug(...) cerr << "[DEBUG] " << #__VA_ARGS__ << ": ", DBG(__VA_ARGS__)
template<typename T> void DBG(const T& v) { cerr << v << endl; }
template<typename T, typename... Args> void DBG(const T& v, const Args&... args) { cerr << v << ", "; DBG(args...); }
#else
#define debug(...)
#endif

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    
    int t;
    cin >> t;

    for (int tc = 1; tc <= t; tc++) {
        int n, k;
        cin >> n >> k;

        vi d(n + 1);
        for (int i = 1; i <= n; i++) cin >> d[i];

        vector<vi> adj(n + 1);
        vi deg(n + 1, 0);
        for (int i = 0; i < k; i++) {
            int x, y;
            cin >> x >> y;
            adj[x].pb(y);
            deg[y]++;
        }

        int w;
        cin >> w;

        queue<int> q;
        vi dp(n + 1, 0);

        for (int i = 1; i <= n; i++) {
            if (deg[i]) continue;
            dp[i] = d[i];
            q.push(i);
        }

        while (!q.empty()) {
            int cur = q.front();
            q.pop();

            for (int nxt : adj[cur]) {
                dp[nxt] = max(dp[nxt], dp[cur] + d[nxt]);
                deg[nxt]--;
                if (deg[nxt]) continue;
                q.push(nxt);
            }
        }

        int ans = dp[w];
        debug(tc, w, ans);
        cout << ans << '\n';
    }
    
    return 0;
}
```

## 검증

### 시간복잡도

- 테스트케이스 하나당 O(N + K)
- 모든 건물과 규칙을 한 번씩만 처리하므로 제한 내에서 충분히 통과 가능하다.

### 공간복잡도

- O(N + K)
- 인접 리스트, 진입차수, 완료 시각 배열만 사용한다.

### 코너 케이스

- 선행 건물이 전혀 없는 목표 건물
- 여러 선행 경로 중 하나가 매우 길어 최대 완료 시각이 바뀌는 경우
- 건설 시간이 0인 건물이 섞인 경우
- 여러 테스트케이스에서 이전 상태가 남아 오답이 나는 경우
