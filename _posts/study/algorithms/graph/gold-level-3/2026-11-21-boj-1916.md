## 문제 태그

- 그래프 이론
- 최단 경로
- 다익스트라

## 아이디어

- 주어진 엣지를 그래프로 구성한 뒤에 [Dijkstra](/study/algorithms/graph/dijkstra/) 로 최단경로를 구한다.

## 정답

```python
import sys
import heapq

def dijkstra(graph, node_size, source):
    INF = float('inf')
    dist = [INF] * node_size
    dist[source] = 0
    heap = [(0, source)]

    while heap:
        cost, node = heapq.heappop(heap)

        if dist[node] < cost:
            continue

        for to, w in graph.get(node, []):
            new_cost = cost + w
            if new_cost < dist[to]:
                dist[to] = new_cost
                heapq.heappush(heap, (new_cost, to))

    return dist

input = sys.stdin.readline

N = int(input())
M = int(input())

graph = {}

for _ in range(M):
    start, end, cost = map(int, input().split())
    start_idx = start - 1
    end_idx = end - 1

    if start_idx not in graph:
        graph[start_idx] = []
    graph[start_idx].append((end_idx, cost))

start_node, end_node = map(int, input().split())

distances = dijkstra(graph, N, start_node - 1)

print(distances[end_node - 1])
```
