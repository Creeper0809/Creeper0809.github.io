## 아이디어

문제가 요구하는 프로세서는 총 4단계

1. 영역탐사를 해서 뿌요가 4개 뭉처있는 구간 전부 확인
2. 4개 뭉처있는 구간 전부 부시기
3. 남아있는 뿌요 끌어내리기
4. 1~3번을 더 이상 반복 못 할때까지 반복

여기서 중요한점은 끌어 내릴 때 위에서부터하면 겹칠 가능성이 있으니 아래서부터 내리는게 중요하다

첫번째 시도에서는 4개 뿌실때 마다 하나의 체인인줄 알고 그렇게 했다 틀렸다

두번째 시도에서는

| b | b |
| --- | --- |
| . | . |
| b | b |
| . | . |

이런 상황에서 가장 밑에꺼만 얼만큼 땡겨야 하는지 계산 했다 가운데에 빈 공간이 있다면 그만큼 또 땡겨줘야한다는걸 깜빡했다

세번째시도에서는 원래 부셔진 뿌요가 있는 열만 체크했었는데 그게 어떤 반례가 있었는지 안됐었다

## 첫번째 시도

```python
from collections import deque
R,C = 12,6
graph = list()
dir = [[1,0],[-1,0],[0,-1],[0,1]]
for i in range(R):
    graph.append(list(input()))

def bfs(start,visited):
    queue = deque()
    queue.append((start[0],start[1]))
    visited[start[0]][start[1]] = True
    alpabet = graph[start[0]][start[1]]
    group = list()
    group.append(start)
    while queue:
        r,c = queue.popleft()
        for dr,dc in dir:
            ddr = r + dr
            ddc = c + dc
            if 0<=ddr<R and 0<=ddc<C and not visited[ddr][ddc] and alpabet == graph[ddr][ddc]:
                visited[ddr][ddc] = True
                queue.append((ddr,ddc))
                group.append((ddr,ddc))
    if len(group) > 3:
        breakPuyo(group)
        return True
    return False

def breakPuyo(groups):
    rowarr = set()
    for r,c in groups:
        graph[r][c] = -1
        if r not in rowarr:
            rowarr.add(c)
    for i in rowarr:
        row = [t[i] for t in graph]
        where = row.index(-1)
        howmuch = row.count(-1)
        for j in range(where-1,0,-1):
            if graph[j][i] != ".":
                graph[j+howmuch][i] = graph[j][i]
                graph[j][i] = "."
    for i in range(R):
        for j in range(C):
            if graph[i][j] == -1:
                graph[i][j] = "."
chain = 0
def checkPna():
    global chain
    visited = [[False] * C for _ in range(R)]
    for i in range(R):
        for j in range(C):
            if graph[i][j] != "." and not visited[i][j]:
                group = bfs((i, j),visited)
                if group:
                    chain += 1
                    return True
    return False

while True:
    breaked = checkPna()
    if not breaked:
        break
print(chain)
```
