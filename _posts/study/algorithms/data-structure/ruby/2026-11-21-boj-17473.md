## 아이디어

1. 웰논 알고리즘인 세그먼트 트리 비트 문제이다.
2. Lazy Propagation 세그먼트 트리와 다른 점은 트리의 가지치기 시점(Breakpoint)과 자식 태그 조건(Tag Condition)을 적당하게 조절해서 업데이트 시점을 정하는 것이다.
3. OR 연산 업데이트의 태그 조건 및 가지치기
    1. **이미 켜진 비트는 업데이트할 필요 없음**
        - 구간 [start,end]의 모든 원소에 대해 해당 비트가 모두 1이면,
        OR 연산을 적용해도 결과는 변하지 않는다.
        - 즉, 그 구간의 **one_mask**에 이미 1이 기록된 비트들은 업데이트 대상에서 제외할 수 있다.
        - 그래서 value &= (~now_node.one_mask) & ALL와 같이 현재 노드의 one_mask에 해당하는 비트를 제거한다.
    2. **0인 비트만 업데이트 대상**
        - OR 연산은 0인 비트에 대해서만 값이 달라진다.
        - 현재 구간의 **zero_mask**는 모든 원소에서 0인 비트의 위치를 나타낸다.
        - 따라서 value에서 남은 비트와 zero_mask의 교집합이 있다면,
        그 비트는 실제로 구간 업데이트를 통해 1로 바뀔 수 있는 후보이다.
        - 이 때,
            
            ```python
            if left <= start and end <= right and (value & now_node.zero_mask):
                update_bits = value & now_node.zero_mask
                now_node.lazy_or = update_bits
                value &= (~update_bits) & ALL
                apply(node, start, end)
            
            ```
            
            와 같이, 구간이 완전히 포함된 경우 해당 비트를 lazy 태그에 등록하고 바로 적용할 수 있다.
            
    3. **재귀적 업데이트 후 추가 확인**
        - 재귀 호출로 자식 노드들을 업데이트하고 난 후,
        자식들의 정보가 갱신되면서 부모 노드의 one_mask 혹은 zero_mask가 바뀔 수 있다.
        - 그 결과, 여전히 업데이트가 필요한 비트가 남아있다면 추가로 lazy 태그를 적용하는 과정을 거친다.
        - 이 보완 과정을 통해 구간 전체에 대해 OR 연산이 완전히 반영되도록 한다.
4. AND 연산 업데이트의 태그 조건. OR 연산과 반대되는 양상을 보인다.
    1. **이미 꺼진 비트는 업데이트할 필요 없음**
        - 구간 [start,end]의 모든 원소에 대해 해당 비트가 모두 0이면,
        AND 연산으로도 결과는 0이므로 변화가 없다.
        - 이때, 해당 구간의 **zero_mask**에 이미 1이 표시된 비트는 업데이트할 필요가 없다.
        - 따라서 AND 연산에서는 X의 0인 비트(즉, 강제로 0으로 만들어야 할 부분)를
        현재 구간에서 제거해서 업데이트 대상에서 배제하는 방식으로 진행한다.
    2. **업데이트해야 할 비트는 1인 상태에서 0으로 바꿔야 하는 부분**
        - 남은 업데이트 대상 비트들은 구간 내 원소들이 모두 1인 상태여야 의미 있게 AND 연산을 적용할 수 있다.
        - 이를 위해 AND 연산 업데이트에서는 OR 연산과 유사하게,
        현재 노드의 one_mask를 확인하여 이미 0인 비트와 구분하고,
        필요한 경우 lazy 태그 (lazy_and)를 설정하여 1을 0으로 만드는 동작을 예약한다.
    3. **OR와 대칭적인 처리**
        - OR 연산이 0에서 1로 전환하는 연산이라면,
        AND 연산은 1에서 0으로 전환하는 연산이다.
        - 태그 조건, 가지치기, 그리고 lazy 업데이트가 기본 구조는 OR 연산과 거의 유사하지만,
        검사하는 대상 마스크(1에 대해서는 one_mask, 0에 대해서는 zero_mask)가 반대가 되는 것이다.

## 정답

```python
import sys; input = sys.stdin.readline
sys.setrecursionlimit(10**5)

BITS = 20
ALL = (1 << BITS) - 1
N = int(input())
arr = list(map(int,input().split()))

class Node:
    def __init__(self):
        self.max_val = -1
        self.one_mask = 0
        self.zero_mask = ALL
        self.lazy_and = 0
        self.lazy_or = 0

seg_tree = [Node() for _ in range(N * 4)]

def build_tree(node, start, end):
    if start == end:
        seg_tree[node].max_val = arr[start]
        seg_tree[node].one_mask = arr[start]
        seg_tree[node].zero_mask = (~arr[start]) & ALL
        return

    mid = (start + end) // 2
    build_tree(node * 2, start, mid)
    build_tree(node * 2 + 1, mid + 1, end)

    left_node = seg_tree[node * 2]
    right_node = seg_tree[node * 2 + 1]

    seg_tree[node].max_val = max(left_node.max_val, right_node.max_val)
    seg_tree[node].one_mask = left_node.one_mask & right_node.one_mask
    seg_tree[node].zero_mask = left_node.zero_mask & right_node.zero_mask

def apply(node, start, end):
    now_node = seg_tree[node]

    now_node.max_val |= now_node.lazy_or
    now_node.one_mask |= now_node.lazy_or
    now_node.zero_mask &= (~now_node.lazy_or) & ALL

    now_node.max_val &= (~now_node.lazy_and) & ALL
    now_node.one_mask &= (~now_node.lazy_and) & ALL
    now_node.zero_mask |= now_node.lazy_and

    if start != end:
        left_node = seg_tree[node * 2]
        right_node = seg_tree[node * 2 + 1]

        left_node.lazy_or &= (~now_node.lazy_and) & ALL
        left_node.lazy_and &= (~now_node.lazy_or) & ALL
        left_node.lazy_or |= now_node.lazy_or
        left_node.lazy_and |= now_node.lazy_and

        right_node.lazy_or &= (~now_node.lazy_and) & ALL
        right_node.lazy_and &= (~now_node.lazy_or) & ALL
        right_node.lazy_or |= now_node.lazy_or
        right_node.lazy_and |= now_node.lazy_and

    now_node.lazy_or = 0
    now_node.lazy_and = 0

def query(node, start, end,left,right):
    apply(node, start, end)
    if right < start or left > end:
        return -1
    if left <= start and end <= right:
        return seg_tree[node].max_val
    mid = (start+end)//2
    return max(query(node * 2,start,mid,left,right), query(node*2 + 1,mid+1,end,left,right))

def update_or(node, start, end,left,right,value):
    apply(node, start, end)
    if right < start or left > end:
        return

    now_node = seg_tree[node]
    value &= (~now_node.one_mask) & ALL

    if left <= start and end <= right and (value & now_node.zero_mask):
        update_bits = value & now_node.zero_mask
        now_node.lazy_or = update_bits
        value &= (~update_bits) & ALL
        apply(node, start, end)

    if value == 0:
        return

    mid = (start + end) // 2

    update_or(2 * node, start, mid, left, right, value)
    update_or(2 * node + 1, mid + 1, end, left, right, value)

    left_node = seg_tree[2 * node]
    right_node = seg_tree[2 * node + 1]

    seg_tree[node].one_mask = left_node.one_mask & right_node.one_mask
    seg_tree[node].zero_mask = left_node.zero_mask & right_node.zero_mask
    seg_tree[node].max_val = max(left_node.max_val, right_node.max_val)

def update_and(node, start, end,left,right,value):
    apply(node, start, end)
    if right < start or left > end:
        return

    now_node = seg_tree[node]
    value &= (~now_node.zero_mask) & ALL

    if left <= start and end <= right and (value & now_node.one_mask):
        update_bits = value & now_node.one_mask
        now_node.lazy_and = update_bits
        value &= (~update_bits) & ALL
        apply(node, start, end)

    if value == 0:
        return

    mid = (start + end) // 2

    update_and(2*node, start, mid, left, right, value)
    update_and(2*node + 1, mid + 1, end, left, right, value)

    left_node = seg_tree[2*node]
    right_node = seg_tree[2*node+1]

    seg_tree[node].one_mask = left_node.one_mask & right_node.one_mask
    seg_tree[node].zero_mask = left_node.zero_mask & right_node.zero_mask
    seg_tree[node].max_val = max(left_node.max_val, right_node.max_val)

build_tree(1,0,N-1)

M = int(input())
query_result = []
for _ in range(M):
    query_list = list(map(int, input().split()))
    if query_list[0] == 1:
        update_and(1,0,N-1,query_list[1] - 1,query_list[2] - 1,(~query_list[3]) & ALL)
    elif query_list[0] == 2:
        update_or(1,0,N-1,query_list[1] - 1,query_list[2] - 1,query_list[3])
    else:
        query_result.append(query(1,0,N-1,query_list[1] -1 ,query_list[2] - 1))

print("\n".join(map(str,query_result)))
```
