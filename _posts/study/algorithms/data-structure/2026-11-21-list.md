## 연결리스트

연결리스트는 데이터를 순서대로 저장하는 자료구조이다. 각각의 데이터는 노드(node)라는 단위로 구성되어 있으며, 각 노드는 데이터와 다음 노드를 가리키는 포인터(pointer)로 이루어져 있다.

연결리스트는 배열과 달리 데이터를 연속적으로 저장하지 않기 때문에 삽입, 삭제 작업이 용이하다. 또한, 배열과 달리 크기를 미리 지정하지 않아도 되기 때문에 동적으로 메모리를 할당할 수 있다.

## 예시

다음은 정수형 데이터를 저장하는 단순 연결리스트의 예시이다.

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = Node(data)
        if self.head is None:
            self.head = new_node
            return
        last_node = self.head
        while last_node.next:
            last_node = last_node.next
        last_node.next = new_node

    def print_list(self):
        current_node = self.head
        while current_node:
            print(current_node.data)
            current_node = current_node.next

```

## 연결리스트의 장점

- 삽입 및 삭제 작업이 배열에 비해 용이
- 동적으로 메모리를 할당

## 연결리스트의 단점

- 특정 인덱스에 직접 접근 불가
- 노드마다 포인터를 저장해야 하므로, 저장공간이 배열에 비해 더 많이 필요
- 배열과 달리 캐시 지역성(cache locality)을 가지지 않아, 메모리 접근이 느림

## 연결리스트의 삽입과 삭제 과정

삽입 과정은 다음과 같다:

1. 삽입할 데이터를 담은 새로운 노드를 만든다.
2. 새로운 노드가 삽입될 위치를 가리키는 포인터를 찾는다. (ex. 새로운 노드가 3번째에 삽입될 경우, 2번째 노드의 포인터를 찾는다.)
3. 새로운 노드가 삽입될 위치를 가리키는 포인터를 새로운 노드가 가리키게 한다.
4. 이전 노드의 포인터를 새로운 노드가 가리키게 한다.

삭제 과정은 다음과 같다:

1. 삭제할 노드를 가리키는 포인터를 찾는다.
2. 이전 노드의 포인터를 삭제할 노드의 포인터가 가리키는 노드로 변경한다.
3. 삭제할 노드를 제거한다.

연결리스트의 삽입과 삭제는 배열에 비해 용이하다. 특히 삽입 과정에서는 배열의 경우 삽입할 위치 이후의 모든 데이터를 한 칸씩 뒤로 이동시켜야 하지만, 연결리스트는 단순히 포인터만 변경하면 되므로 이러한 작업이 필요하지 않다. 또한, 동적으로 메모리를 할당할 수 있기 때문에 필요한 만큼의 메모리만 사용할 수 있다. 하지만 배열과 달리 특정 인덱스에 직접 접근할 수 없고, 노드마다 포인터를 저장해야 하므로 저장공간이 배열에 비해 더 많이 필요하다. 또한, 배열과 달리 캐시 지역성을 가지지 않아 메모리 접근이 느리다는 단점이 있다.

## 원형 연결 리스트

원형 연결 리스트는 단순 연결 리스트와 유사하지만, 마지막 노드가 첫 번째 노드를 가리키는 특징이 있다. 이렇게 하면, 마지막 노드의 다음 노드가 첫 번째 노드가 되므로, 리스트의 끝과 시작이 결합된다.

이러한 특징은 원형 연결 리스트를 사용하는 알고리즘에서 매우 유용할 수 있다. 예를 들어, 큐(queue)를 구현할 때, 원형 연결 리스트를 사용하여 첫 번째 노드와 마지막 노드를 쉽게 유지할 수 있다.

원형 연결 리스트에서 삽입 및 삭제 작업은 단순 연결 리스트와 마찬가지로 동작한다. 다만, 마지막 노드를 처리해야 한다는 점이 다르다.

## 예시

다음은 정수형 데이터를 저장하는 원형 연결 리스트의 예시이다.

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class CircularLinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = new_node
            self.head.next = self.head
        else:
            current_node = self.head
            while current_node.next != self.head:
                current_node = current_node.next
            current_node.next = new_node
            new_node.next = self.head

    def print_list(self):
        current_node = self.head
        while current_node.next != self.head:
            print(current_node.data)
            current_node = current_node.next
        print(current_node.data)

```

## 원형 연결 리스트의 장점

- 순서대로 데이터를 저장
- 삽입 및 삭제 작업이 배열에 비해 용이

## 원형 연결 리스트의 단점

- 특정 인덱스에 직접 접근 불가
- 노드마다 포인터를 저장해야 하므로, 저장공간이 배열에 비해 더 많이 필요
- 배열과 달리 캐시 지역성(cache locality)을 가지지 않아, 메모리 접근이 느리다는 단점

## 원형 연결 리스트의 삽입과 삭제 과정

삽입 과정은 단순 연결 리스트와 유사합니다. 다만, 마지막 노드를 처리해야 한다는 점이 다르다.

1. 삽입할 데이터를 담은 새로운 노드를 만든다.
2. 새로운 노드가 삽입될 위치를 가리키는 포인터를 찾는다. (ex. 새로운 노드가 3번째에 삽입될 경우, 2번째 노드의 포인터를 찾는다. 이 때, 마지막 노드의 포인터도 고려해야 한다.)
3. 새로운 노드가 삽입될 위치를 가리키는 포인터를 새로운 노드가 가리키게 한다.
4. 이전 노드의 포인터를 새로운 노드가 가리키게 한다.

삭제 과정도 단순 연결 리스트와 유사하다. 다만, 마지막 노드를 처리해야 한다는 점이 다르다.

1. 삭제할 노드를 가리키는 포인터를 찾는다.
2. 이전 노드의 포인터를 삭제할 노드의 포인터가 가리키는 노드로 변경한다.
3. 삭제할 노드를 제거한다.

## 이중 연결 리스트

이중 연결 리스트(doubly linked list)는 일반적인 연결 리스트와 유사하지만, 각 노드가 다음 노드와 이전 노드를 모두 가리키는 특징이 있다. 이러한 특징은 리스트의 양쪽 끝에서부터 탐색할 수 있도록 해주고, 삽입 및 삭제 작업이 일반적인 연결 리스트보다 더욱 쉬워지도록 한다.

이중 연결 리스트에서 각 노드는 다음 노드와 이전 노드를 모두 가리키는 포인터를 가지고 있다. 이러한 포인터는 리스트의 양쪽 끝에서부터 탐색할 수 있도록 해주며, 삽입 및 삭제 작업이 일반적인 연결 리스트보다 더욱 쉬워지도록 한다.

## 예시

다음은 정수형 데이터를 저장하는 이중 연결 리스트의 예시이다.

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None
        self.prev = None

class DoublyLinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = new_node
        else:
            current_node = self.head
            while current_node.next:
                current_node = current_node.next
            current_node.next = new_node
            new_node.prev = current_node

    def print_list(self):
        current_node = self.head
        while current_node:
            print(current_node.data)
            current_node = current_node.next

```

## 이중 연결 리스트의 장점

- 양쪽 끝에서부터 탐색이 가능
- 삽입 및 삭제 작업이 배열에 비해 용이

## 이중 연결 리스트의 단점

- 각 노드마다 두 개의 포인터를 저장해야 하므로, 저장공간이 배열에 비해 더 많이 필요
- 배열과 달리 캐시 지역성(cache locality)을 가지지 않아, 메모리 접근이 느리다는 단점

## 이중 연결 리스트의 삽입과 삭제 과정

이중 연결 리스트에서의 삽입과 삭제 과정은 다음과 같다:

1. 삽입 과정
    - 삽입할 데이터를 담은 새로운 노드를 만든다.
    - 새로운 노드가 삽입될 위치를 가리키는 포인터를 찾는다. (예를 들어, 새로운 노드가 3번째에 삽입될 경우, 2번째 노드의 포인터를 찾는다.)
    - 새로운 노드가 삽입될 위치를 가리키는 포인터를 새로운 노드가 가리키게 한다.
    - 새로운 노드의 이전 노드 포인터를 이전 노드가 새로운 노드를 가리키게 한다.
    - 새로운 노드의 다음 노드 포인터를 다음 노드가 새로운 노드를 가리키게 한다.
2. 삭제 과정
    - 삭제할 노드를 가리키는 포인터를 찾는다.
    - 삭제할 노드의 이전 노드 포인터를 삭제할 노드의 다음 노드가 가리키는 노드로 변경한다.
    - 삭제할 노드의 다음 노드 포인터를 다음 노드가 삭제할 노드의 이전 노드를 가리키게 한다.
    - 삭제할 노드를 제거한다.

위의 과정에서, 이중 연결 리스트의 특징인 각 노드가 다음 노드와 이전 노드를 모두 가리키는 포인터를 가지고 있기 때문에, 이전 노드를 찾는 과정이 단순 연결 리스트에 비해 간단해진다. 또한, 삽입과 삭제 과정에서 이전 노드와 다음 노드 모두를 변경해야 하기 때문에, 이중 연결 리스트에서는 각 노드가 다음 노드와 이전 노드를 모두 가리키는 포인터를 가지고 있어야 한다.

## 선형리스트/배열

배열(array)은 동일한 데이터 타입의 항목이 메모리 상에 연속적으로 저장된 자료 구조이다. 배열은 인덱스를 사용하여 데이터에 직접적으로 접근할 수 있기 때문에, 데이터의 검색이나 정렬과 같은 작업에서 빠른 속도를 보인다. 또한, 고정된 크기를 가지므로 메모리를 효율적으로 사용할 수 있다. 하지만, 배열의 크기가 고정되어 있어서 크기를 변경하기 어렵다는 단점이 있다. 또한, 배열의 중간에 삽입이나 삭제 작업을 수행할 때, 모든 항목의 위치를 이동시켜야 하는 단점이 있다. 이러한 단점을 극복하기 위해 동적 배열(dynamic array)이나 연결 리스트(linked list)와 같은 자료 구조가 사용된다.

### 예시)

```python
arr = [1, 2, 3, 4, 5] # 정수형 데이터를 담은 배열
arr.append(6) # 배열에 6 추가
arr.pop() # 배열에서 가장 마지막 항목 제거
arr[2] = 7 # 배열의 3번째 항목을 7로 변경
print(arr) # 배열의 내용 출력: [1, 2, 7, 4, 5]
```

배열에서 삽입과 삭제 과정은 다음과 같다:

1. 삽입 과정
    - 삽입할 데이터를 담은 새로운 원소를 만든다.
    - 삽입할 위치 이후의 모든 원소를 한 칸씩 뒤로 이동시킨다.
    - 새로운 원소를 삽입할 위치에 저장한다.
2. 삭제 과정
    - 삭제할 원소의 위치를 찾는다.
    - 삭제할 원소 이후의 모든 원소를 한 칸씩 앞으로 이동시킨다.
    - 마지막 원소를 삭제한다.

위의 과정에서, 삽입 과정에서는 이후의 모든 원소를 이동시켜야 하기 때문에 배열의 크기가 클수록 삽입 속도가 느려진다. 또한, 삭제 과정에서도 이후의 모든 원소를 이동시켜야 하기 때문에 삭제 속도도 느려진다.  반면에 검색 작업에서는 인덱스를 사용하여 데이터에 직접적으로 접근할 수 있기 때문에 빠른 속도를 보인다.

## 배열과 연결리스트의 차이점

배열과 연결 리스트는 각각 다음과 같은 활용점이 있다.

### 배열

- 데이터를 검색하는 작업에서 빠른 속도를 보인다.
- 고정된 크기를 가지므로, 메모리를 효율적으로 사용할 수 있다.
- 데이터의 삽입, 삭제 작업이 빈번하게 일어나지 않는 경우 사용하기 적합하다.

### 연결 리스트

- 데이터의 삽입, 삭제 작업이 빈번하게 일어나는 경우 사용하기 적합하다.
- 저장공간이 배열에 비해 더 많이 필요하다.
- 노드마다 포인터를 저장해야 하므로, 캐시 지역성을 가지지 않아 메모리 접근이 느리다.
- 각 노드가 다음 노드와 이전 노드를 모두 가리키는 포인터를 가지고 있어, 양쪽 끝에서부터 탐색 가능하며, 삽입 및 삭제 작업이 쉬워진다.
