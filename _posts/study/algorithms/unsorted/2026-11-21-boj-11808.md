## 문제 태그

- 동적 계획법
- 트리
- 트리 DP
- 배낭 문제

## 아이디어

- 시작점인 루트까지 포함해 방문할 성 K+1개를 원형으로 놓고, 인접한 두 성 사이를 최단 경로로 이동한다고 생각한다. 간선 하나를 끊었을 때 자식 쪽에서 선택한 성이 j개라면 반대쪽에는 K+1−j개가 있다.
- 이 간선을 지날 때는 양쪽을 번갈아 방문한다. 따라서 횟수는 최대 2 × min(j, K+1−j)다. 선택된 성의 개수를 기준으로 트리의 중심점을 잡으면 각 가지에 전체의 절반 이하가 들어간다. 같은 가지가 연달아 나오지 않게 성을 원형으로 배치하면 각 간선의 작은 쪽 성도 연달아 나오지 않아 위의 상한을 동시에 채울 수 있다.
- dp[u][k]는 u의 서브트리에서 성 k개를 골랐을 때 얻을 수 있는 간선 기여도의 최댓값이다. 자식 v를 합칠 때 선택 개수를 배낭 DP처럼 배분하고, 간선 비용에 min(j, K+1−j)를 곱해서 더한다. 왕복에 해당하는 2는 마지막에 한 번에 곱한다.

루트는 처음부터 방문 목록에 포함되므로 DP에서 다시 선택하지 않는다. 자식마다 최대 K개를 두 그룹으로 배분하므로 시간은 O(NK²), DP 표의 공간은 O(NK)다.

## 정답

```python
import sys
sys.setrecursionlimit(100000)
input = sys.stdin.readline

T = int(input())
for cas in range(1, T + 1):
    N, K = map(int, input().split())
    children = [[] for _ in range(N + 1)]
    for i in range(2, N + 1):
        p, c = map(int, input().split())
        children[p].append((i, c))

    INF = 10**18
    dp = [[-INF] * (K + 1) for _ in range(N + 1)]

    def dfs(u):
        if not children[u]:
            dp[u][0] = 0
            if u != 1:
                dp[u][1] = 0
            return

        curr = [-INF] * (K + 1)
        curr[0] = 0
        for v, cv in children[u]:
            dfs(v)
            new_curr = [-INF] * (K + 1)
            for prev in range(K + 1):
                if curr[prev] == -INF:
                    continue
                for jv in range(K - prev + 1):
                    if dp[v][jv] == -INF:
                        continue
                    min_val = min(jv, K - jv + 1)
                    add = dp[v][jv] + cv * min_val
                    new_curr[prev + jv] = max(new_curr[prev + jv], curr[prev] + add)
            curr = new_curr

        for j in range(K + 1):
            if curr[j] != -INF:
                dp[u][j] = max(dp[u][j], curr[j])
                if u != 1 and j + 1 <= K:
                    dp[u][j + 1] = max(dp[u][j + 1], curr[j])

    dfs(1)
    ans = 2 * dp[1][K] if dp[1][K] != -INF else 0
    print(f"Case {cas}: {ans}")
```
