## 아이디어

- 철판의 두 변 중 하나를 너비로 쓰면 나머지가 검의 길이에 더해진다. 두 변의 합은 고정이므로, 철판마다 서로 다른 너비를 고르면서 너비 합을 최소로 만들면 된다.
- 너비 후보를 정점, 철판을 두 후보 사이의 간선으로 둔다. 같은 너비를 가진 철판끼리 유니온 파인드로 묶으면 각 묶음을 따로 풀 수 있다. 간선마다 서로 다른 정점을 하나 골라야 하므로, 가능한 입력에서 연결 요소는 트리이거나 사이클이 하나인 형태로만 나온다.
- 트리는 정점이 간선보다 하나 많다. 가장 큰 너비를 루트로 두고 각 간선이 자식 쪽 너비를 고르면 가장 비싼 후보 하나만 빼고 전부 쓸 수 있다. 사이클이 있는 경우는 정점과 간선 수가 같아서 모든 후보를 써야 한다. 사이클을 따라 방향을 주고 나머지 가지에서는 자식 쪽을 고르면 된다.

결국 묶음에 철판이 k개 있으면 서로 다른 너비 중 작은 것부터 k개를 더하면 된다. 이 합을 전체 변 길이 합에서 빼고, 고른 너비가 큰 철판부터 놓으면 된다. 정렬이 병목이라 시간은 O(N log N)이다.

## 정답

```python
import sys
from collections import defaultdict

input = sys.stdin.readline

class UnionFind:
    def __init__(self, n):
        self.parent = [i for i in range(n)] # 각 원소의 부모는 자기 자신
        self.rank = [1] * n # 트리의 높이 또는 랭크
        self.set_size = [1] * n # 각 집합의 크기 (option, size tracking)
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x]) # 경로 압축
        return self.parent[x]
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return False # 이미 같은 집합
        # 랭크를 기준으로 루트 노드를 선택
        if self.rank[x_root] < self.rank[y_root]:
            x_root, y_root = y_root, x_root
        self.parent[y_root] = x_root
        if self.rank[x_root] == self.rank[y_root]:
            self.rank[x_root] += 1
        self.set_size[x_root] += self.set_size[y_root]
        return True
    def same(self, x, y):
        return self.find(x) == self.find(y)
    def size(self, x):
        return self.set_size[self.find(x)]

n = int(input().strip())
plates = [None] * (n + 1)
total = 0
points = []

for i in range(1, n + 1):
    s, t = map(int, input().split())
    plates[i] = (s, t)
    total += s + t
    points.append((s, i))
    points.append((t, i))

points.sort()

uf = UnionFind(n + 1)

for j in range(1, len(points)):
    if points[j - 1][0] == points[j][0]:
        uf.union(points[j - 1][1], points[j][1])

groups = defaultdict(list)
for i in range(1, n + 1):
    root = uf.find(i)
    groups[root].append(i)

sum_w = 0
for root, idxs in groups.items():
    cnt = len(idxs)
    possible = set()
    for idx in idxs:
        s, t = plates[idx]
        possible.add(s)
        possible.add(t)
    loc = sorted(possible)
    sum_w += sum(loc[:cnt])

print(total - sum_w)
```
