파라메트릭 서치는 최솟값이나 최댓값을 구하는 문제에서 답의 후보를 정하고, 그 값으로 조건을 만족할 수 있는지 검사하는 방법이다. 예를 들어 ‘최소 운반 용량은 얼마인가?’를 ‘용량이 X일 때 정해진 횟수 안에 모두 옮길 수 있는가?’로 바꾼다.

## 가능 여부의 경계 찾기

후보를 작은 값부터 늘렸을 때 가능 여부가 한 방향으로만 바뀌어야 한다. 운반 용량 X로 짐을 모두 옮길 수 있다면 그보다 큰 용량으로도 가능하므로, 처음으로 가능한 용량을 이분 탐색으로 찾을 수 있다.

| 구하는 값 | 후보가 커질 때 가능 여부 | 찾는 위치 |
| --- | --- | --- |
| 최소 운반 용량 | 불가능 → 가능 | 첫 번째 가능한 값 |
| 최대 랜선 길이 또는 최대 절단 높이 | 가능 → 불가능 | 마지막으로 가능한 값 |

탐색할 범위부터 정하고, 가능 여부를 한 번 검사하는 데 걸리는 시간을 따로 계산한다. 후보가 M개이고 판정 한 번에 T가 걸리면 전체 시간은 `O(T log(M + 1))`이다. 공유기 설치에서는 집을 위치순으로 정렬한 뒤, 후보 거리 이상을 유지하며 앞에서부터 설치해 필요한 개수가 나오는지 판정할 수 있다.

## 예제 · 나무 자르기

높이가 `[20, 15, 10, 17]`인 나무에서 7m 이상을 얻는 최대 절단 높이를 찾는다. 절단 높이가 H이면 높이 `h`인 나무에서 `max(0, h - H)`만큼 얻는다. H를 높여도 얻는 양은 늘지 않으므로, 7m 이상을 얻는 마지막 높이가 답이다. [백준 2805 · 나무 자르기](https://www.acmicpc.net/problem/2805)

| 절단 높이 | 얻는 길이 | 판정 |
| --- | --- | --- |
| 10 | 22m | 가능 |
| 15 | 7m | 가능 |
| 16 | 5m | 불가능 |
| 17 | 3m | 불가능 |

높이 15에서는 `(20 - 15) + (17 - 15) = 7`이므로 조건을 만족한다. 높이 16에서 조건을 만족하지 못하며 이후 높이에서도 얻는 양은 줄어들기만 하므로 답은 15다.

```python
def max_cut_height(heights, required):
    left, right = 0, max(heights)
    best = None

    while left <= right:
        mid = (left + right) // 2
        wood = sum(max(0, height - mid) for height in heights)

        if wood >= required:
            best = mid
            left = mid + 1
        else:
            right = mid - 1

    return best
```

가능한 최댓값을 구하므로 조건을 만족하면 `mid`를 기록하고 더 큰 값을 확인한다. 반대로 가능한 **최솟값**을 구하는 경우, 조건을 만족하면 `right = mid - 1`, 만족하지 않으면 `left = mid + 1`로 바꾼다. 위 코드는 나무 N그루를 판정할 때마다 한 번씩 보므로 최대 높이 H에 대해 `O(N log(H + 1))` 시간이 든다.

## 실수 범위

실수 답도 조건이 바뀌는 경계를 기준으로 범위를 절반씩 줄일 수 있다. 정수 탐색처럼 `mid + 1`로 건너뛰면 사이의 값을 놓치므로, 남기는 구간의 끝을 `mid`로 갱신한다. 요구 오차보다 범위가 좁아지면 멈추거나, 처음 범위와 요구 정밀도에 맞춰 반복 횟수에 상한을 둔다. 부동소수점에서는 `mid`가 이미 한쪽 끝과 같은 값으로 반올림되면 반복을 더 해도 정밀도가 높아지지 않는다.

[Ax + B sin(x) = C 풀이](/study/algorithms/unsorted/boj-13705/)에서는 함수값이 C 이상인지 검사해 실수 범위를 줄이고 마지막에 반올림한다.
